# 🎯 Guide d'Utilisation - Géomarketing Avancé Sandiara

## 🚀 Comment accéder au Géomarketing

### Méthode 1 : Navigation principale
1. Connectez-vous en tant que **Maire**
2. Dans la barre de navigation, cliquez sur **"Géomarketing"**
3. Vous accédez directement à l'interface avancée

### Méthode 2 : Dashboard du Maire
1. Sur votre dashboard, dans la section **"Actions rapides"**
2. Cliquez sur **"Géomarketing Avancé"**

### Méthode 3 : Navigation rapide
1. Cliquez sur le bouton flottant (icône carrés) en bas à droite
2. Sélectionnez **"Géomarketing"** dans le menu

## 🎨 Interface du Géomarketing

### 📊 Filtres d'Analyse (Gauche)
- **Zone** : Sélectionnez une zone spécifique ou "Toutes les zones"
- **Nature d'activité** : Commerce, Services, Industrie, Agriculture
- **Type de commerce** : Boutique, Supermarché, Restaurant, etc.
- **Population** : Définissez les seuils min/max de population
- **Bouton "Analyser"** : Lance l'analyse avec vos critères

### 🗺️ Couches Géographiques
- **Population** : Heatmap de densité démographique
- **Routes** : Réseau routier avec classification
- **Bâti** : Zones bâties avec usage
- **Heatmap population** : Densité d'activité commerciale
- **Carte multi-critères** : Scores d'opportunité combinés

### 📈 Statistiques (Droite)
- **Zones analysées** : Nombre total de zones
- **Score moyen** : Performance globale
- **Zones d'excellence** : Zones avec score ≥ 70
- **Unités totales** : Nombre d'unités commerciales

### 💡 Propositions d'Investissement
- **Score d'opportunité** : Évaluation de 0 à 100
- **Revenus estimés** : Chiffre d'affaires prévisionnel
- **Coût d'investissement** : Montant nécessaire
- **ROI** : Retour sur investissement en %
- **Délai** : Temps de réalisation estimé
- **Risques** : Évaluation des risques

## 🔍 Comment utiliser l'analyse

### 1. Définir vos critères
```
Exemple : Analyser les opportunités pour un supermarché
- Zone : Centre-Ville
- Type : Supermarché
- Population min : 5000
- Population max : 15000
```

### 2. Lancer l'analyse
- Cliquez sur **"Analyser les opportunités"**
- Les résultats apparaissent automatiquement

### 3. Interpréter les résultats
- **Vert (70-100)** : Zone d'excellence
- **Orange (50-69)** : Zone prometteuse  
- **Rouge (<50)** : Zone à développer

### 4. Visualiser sur la carte
- Activez les couches géographiques
- Cliquez sur les zones pour voir les détails
- Utilisez le zoom pour explorer

## 📊 Exemples d'utilisation

### Scénario 1 : Ouverture d'un supermarché
1. **Filtres** : Zone Centre-Ville, Type Supermarché
2. **Résultat** : Score 85/100 - Zone d'excellence
3. **Proposition** : ROI 87.5%, Délai 6-12 mois

### Scénario 2 : Boutique générale
1. **Filtres** : Zone Louly Benteigné, Type Boutique
2. **Résultat** : Score 70/100 - Zone prometteuse
3. **Proposition** : ROI 220%, Délai 3-6 mois

### Scénario 3 : Station-service
1. **Filtres** : Zone Route de Thiès, Type Station
2. **Résultat** : Score 60/100 - Zone modérée
3. **Proposition** : ROI 20%, Délai 8-15 mois

## 🎯 Conseils d'utilisation

### ✅ Bonnes pratiques
- **Testez différents filtres** pour comparer les zones
- **Activez plusieurs couches** pour une vue complète
- **Analysez les risques** avant d'investir
- **Considérez le ROI** et le délai de réalisation

### ⚠️ Points d'attention
- Les données sont basées sur des estimations
- Consultez les autorités locales pour les autorisations
- Évaluez la concurrence existante
- Vérifiez l'accessibilité routière
